What is HTML?

HTML (HyperText Markup Language) is the standard language used to create web pages. It provides the structure of a webpage by using tags and elements.

HTML Tags

An HTML tag is a keyword enclosed inside angle brackets < >.Tags tell the browser what type of content it is dealing with.

Example:<p>This is a paragraph</p>

HTML Elements

An HTML element is the complete structure consisting of the opening tag, content, and closing tag.

Example: <h1>My Heading</h1>

Block-level vs Inline Elements

Block-level elements start on a new line and take up the full width available.

Example:<h1>My Website</h1>

<p>Welcome to my website.</p>

<div>About My Website</div>

Output:My Website

Welcome to my website.

About My Website

Inline elements do not start on a new line and only take up as much width as necessary.

Example:<span>Hello</span>

<span>Students</span>

<span>Welcome.</span>

Output:Hello Students Welcome.

HTML Attributes

An attribute provides additional information about an HTML element.Attributes are written inside the opening tag.

Example:<img src="photo.jpg" alt="My Photo" width="200">

Semantic vs Non-Semantic HTML

Semantic tags clearly tells the browser and developers what the content reprsents.Semantic HTML provides Better Readability,Better Accessibility, Better SEO,Better Maintanability

Example:

<header>

<article>

<footer>

Lists

Lists are used to display a collection of related items.There are three main types of lists.

  1. Unordered List
  2. Ordered List
  3. Description List

1.Unordered List

An unordered list is a list of items without a specific order.It displays items with bullet points

Example:

<ul>

<li>HTML</li>

<li>CSS</li>

<li>JavaScript</li>

<ul>

Output:

  • HTML
  • CSS
  • JavaScript

2.Ordered List

An ordered list is a list of items with a specific order.It displays items with numbers or letters.

Example:

<ol>

<li>Learn HTML</li>

<li>Learn CSS</li>

<li>Learn JavaScript</li>

<ol>

Output:

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript

3.Description List

A description list is a list of terms and their descriptions.

Example:

<dl>

<dt>HTML</dt>

<dd>Used to structure wepages.</dd>

<dt>CSS</dt>

<dd>Used to style webpages.</dd>

<dl>

Output:

HTML
Used to structure webpages.
CSS
Used to style webpages.
